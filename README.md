## Projects

### 🔹 [Gas Station Data Dashboard](https://app-challenge-wi26-hathaway-git-292414558216.us-west3.run.app/)
**[Live Demo](https://app-challenge-wi26-hathaway-git-292414558216.us-west3.run.app/) · [Repository](https://github.com/Logan-Lay21/gas-station-data-dashboard)**

An interactive Streamlit dashboard built for gas station owners to explore store-level sales performance and customer behavior. Built on real transactional data from gas stations across Idaho and Utah.

- Analyzes top-performing products, underperforming beverages, and cash vs. credit purchasing behavior
- Deployed on Google Cloud Run via Docker
- Built with Python, Streamlit, Polars, and Plotly

### 🔹 [Stock Portfolio Competition Analysis](https://Logan-Lay21.github.io/stock-portfolio-analysis)
**[Live Report](https://Logan-Lay21.github.io/stock-portfolio-analysis) · [Repository](https://github.com/Logan-Lay21/stock-portfolio-analysis)**

A head-to-head comparison of two stock portfolios — mine vs. a friend's — using live market data. Pulls real price history, calculates portfolio value over time, and visualizes performance across both picks.

- Pulls live stock data using `tidyquant`
- Multi-stock time series visualizations with deliberate color encoding
- Built with R, tidyquant, tidyverse, and ggplot2

### 🔹 [Historical Height Analysis Across Five Datasets](https://github.com/Logan-Lay21/height-analysis)
**[Repository](https://github.com/Logan-Lay21/height-analysis)**

A cross-century analysis of male height distributions using five datasets spanning Bavarian conscripts, German prison records, SE German soldiers, BLS survey data, and the Wisconsin NSFH. The project focuses on careful data wrangling across very different source formats and honest interpretation of what the data can and can't tell us.

- Harmonized five datasets with different structures, units, and collection methods into a single comparable table
- Violin + boxplot visualization showing height distributions across birth year cohorts
- Written analysis critically evaluating selection bias and limitations
- Built with R, tidyverse, haven, foreign, and ggplot2
